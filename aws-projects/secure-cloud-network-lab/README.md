# Secure AWS Cloud Network and Security Automation Lab

## Project Status

In progress — started September 13, 2026.

## Project Summary

This project will design, deploy, secure, monitor, and test a network environment in AWS. The infrastructure will first be built manually to develop a practical understanding of each component. It will later be reproduced with Terraform and supported by Python and Boto3 automation.

## Planned Capabilities

- Multi-AZ VPC architecture
- Public and private subnets
- Internet gateway and controlled outbound connectivity
- Route tables, security groups, and network ACLs
- EC2 application servers and load balancing
- Least-privilege IAM permissions
- Logging, monitoring, and security detection
- Terraform infrastructure as code
- Python and Boto3 auditing
- Controlled cloud-security testing
- Cost monitoring and resource teardown

## Project Objectives

- Understand how AWS networking components interact.
- Apply cloud security and least-privilege principles.
- Develop infrastructure automation skills.
- Test connectivity and security controls.
- Troubleshoot intentional configuration failures.
- Document design decisions, testing, costs, and lessons learned.
